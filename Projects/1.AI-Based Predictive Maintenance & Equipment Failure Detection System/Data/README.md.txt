
# Dataset Documentation

## Project
AI-Based Predictive Maintenance & Equipment Failure Detection System

## Purpose
The dataset is used to demonstrate a machine learning workflow
for classifying whether a machine observation indicates normal
operation or potential equipment failure.

## Data Source
The project uses a synthetic dataset created for academic
demonstration. It does not represent verified real-world
industrial sensor measurements.

## Target Variable
- `Failure`: 0 = Normal operation
- `Failure`: 1 = Failure risk

## Input Features
The intended input features include:

- Temperature
- Pressure
- Vibration
- Rotational Speed
- Voltage
- Current
- Operating Hours
- Tool Wear
- Machine Type
- Maintenance History

Confirm these names and their exact units against the actual
dataset before publishing.

## Limitations
- Synthetic data may not represent real factory conditions.
- The model's results depend on the data-generation process.
- Predictions are for educational demonstration, not safety-critical
  equipment decisions.
